# Spam Bot using PyAutoGUI
Automates typing of repeated messages/reminders into any focused window.

## Setup
    pip install -r requirements.txt

## Run
    python spam_bot.py --rounds 3 --delay 10
    python spam_bot.py --file messages.txt --rounds 2

Click into the target window (Notepad, WhatsApp Web, etc.) during the countdown.
Abort any time by moving the mouse to the top-left corner or pressing Ctrl+C.
Use only on your own chats/apps - never to flood other people.
